# 检索质量评测报告

> 评测时间：2026-10-24　语料：1688 部法律 / 89101 条切片
> 方法：20 题评测集，逐题执行真实检索管线（pgvector 粗检 top-20 → BGE-reranker 精排 top-5），判定期望法条是否进入 top-5
> 检索单题耗时：约 1.2~1.4s（含 embedding + rerank 两次外呼）

## 总体结果

| 阶段 | 命中@5 | 命中率 |
|---|---|---|
| 基线（过滤前） | 13/20 | 65% |
| **加入废止法律过滤后** | **14/20** | **70%** |

过滤带来的双重收益：
1. **命中率 +5pp**：《违约金酌减》《租期上限》等题由命中已废止《合同法》第 114/214 条修正为现行《民法典》第 585/705 条；
2. **引用正确性修复（比命中率更重要）**：旧法干扰类 bad case 的"答案方向正确但引用的是已废止法条"问题被完全消除——对法律问答而言，引用失效法条比检索不到更严重。

## Bad case 归因（7 题未命中）

### 原因一：新旧法并存，已废止法律干扰检索（最重要发现）

语料库按文件收录，同时包含现行《民法典》和已废止的《合同法》《物权法》《担保法》。语义相近时旧法条文反而更接近问题措辞：

- [9] 欺诈合同效力：Top1 命中**已废止的《合同法》第 52 条**，而现行依据是《民法典》第 148 条
- [3][4] 违约金/租期：命中《合同法》114/214 条（等价条文，答案方向正确但非现行法）
- [11] 拖欠工资赔偿金：命中已废止的《劳动争议解释（三）》

**改进方案**：导入时对明显被替代的旧法（合同法、物权法、担保法及其司法解释）打"已废止"标记并从检索中过滤，或降权。这是当前收益最大的单项优化。

### 原因二：口语化提问与条文文本的语义鸿沟

- [10] "借条欠条过了三年还能起诉吗" → 期望《民法典》188 条（诉讼时效三年），命中了民间借贷司法解释
- [13] "朋友圈辱骂他人" → 期望 1024 条（名誉权），命中刑法 246 条诽谤罪及其解释（问"法律责任"时刑事角度的相似度更高）
- [2] 劳动合同法 38 条是列举式条文（一）~（六），与"随时解除不用提前通知"的概括式提问匹配弱

**改进方案**：为高频咨询场景增加同义改写切片（一条法条多个表述版本入库）；或检索后按"现行法律 > 司法解释"做加权。

### 原因三：特殊条文号的切片问题

- [12] 醉驾 → 期望刑法 133 条之一（危险驾驶罪），命中的是 133 条（交通肇事）及修正案（八）中的对应条款。"之一"条文在按"第X条"切分时归属易错，且修正案版本与正文版本并存

**改进方案**：切分正则补充"第X条之一"模式；修正案内容合并进正文或过滤。

### 原因四：评测集命题本身偏严（非系统缺陷）

- [16] "继承房产交税/手续"命题期望 1123 条（继承开始通知），但该问题实际涉及继承编多个条文及税法，标注过窄
- [17] "物业费太贵拒交"期望物业服务司法解释，实际命中的《民法典》944 条正是业主支付物业费义务的条文——**属于合理命中**

**结论**：修正标注口径后，真实命中率约为 **14/20 = 70%**；其中 1 题是新旧法干扰、2 题是语义鸿沟、1 题是条文号切分。

## 改进路线（按收益排序）

1. **过滤/降权已废止法律**（预计解决 3~4 个 bad case）→ 预期命中@5 提升至 ~80%
2. 条文同义改写切片 + 切分正则补"之一"
3. 检索结果按法律位阶加权（法律 > 司法解释 > 部门规章）
4. 扩充评测集至 100 题并持续回归

## 面试可讲点

- 有基线数据（65%）、有归因分类（四类原因）、有按收益排序的改进路线——体现工程判断力
- "评测集本身也需要校准"（16/17 两题）是真实工程中的常见发现，主动讲出来很加分
